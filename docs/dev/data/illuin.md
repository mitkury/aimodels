# ILLUIN Technology

The [November 23 release](https://huggingface.co/blog/QuentinJG/ive-release)
introduces Apache-2.0 decision models for document understanding. The
[IVE card](https://huggingface.co/illuin/IVE-4B) and
[Ivonnet card](https://huggingface.co/illuin/Ivonnet-0.8B) establish the
checkpoint IDs. Both take text or images and return scores for choices without
generating text. A native context ceiling and hosted selectors are unverified.
The [company announcement](https://www.illuin.tech/wp-content/uploads/2025/03/Lancement-Dialogue-2025-ILLUIN-Technology-06_02_2025-1.pdf)
documents ILLUIN's founding and location.
