# BharatGen

- [BharatGen launch](https://bharatgen.com/blogs/bharatgen-launches-with-dst/)
- [Patram 1.5 announcement](https://bharatgen.com/blogs/introducing-patram-1-5/)
- [Patram 1.5 model card](https://huggingface.co/bharatgenai/Patram1.5-7B)

The November 26 release documents Apache 2.0 weights, a 32,768-token
context window, and image and text input with text output for document
parsing and visual question answering. The weights are available through
Hugging Face's automatic access gate. BharatGen's Playground offers the
model interactively, and its model directory describes a future API.
