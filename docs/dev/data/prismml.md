## November 27, 2026 audit

PrismML released Ternary Bonsai 2.5 27B on November 24.
The [model card](https://huggingface.co/prism-ml/Ternary-Bonsai-2.5-27B-GGUF)
and [weight upload](https://huggingface.co/prism-ml/Ternary-Bonsai-2.5-27B-GGUF/commit/f71afa90d5f8f07f0518b6105eaf9b50e2c6d210)
establish Apache 2.0 weights, 262,144 tokens of context, reasoning and
tool calling. Image input requires the separately distributed vision projector.
The [release collection](https://huggingface.co/collections/prism-ml/bonsai-25-27b)
also publishes MLX weights for the same model.
