# Aleph Alpha

The [November 23 announcement](https://aleph-alpha.com/en/news/kolibri-1-1-release/)
and [weight release](https://huggingface.co/Aleph-Alpha/Kolibri-1.1/commit/e9515166e22131ef3f3f486127fe89b96c2a0e2c)
establish the Apache-2.0 checkpoint `Aleph-Alpha/Kolibri-1.1`. Its
[model card](https://huggingface.co/Aleph-Alpha/Kolibri-1.1) documents
262,144 native tokens, optional extension to 1,048,576 tokens, reasoning,
and tool calling in vLLM. The catalog uses the native limit.
[Aleph Alpha's newsroom](https://aleph-alpha.com/en/news/) documents the
company's founding and location.
