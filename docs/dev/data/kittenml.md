# KittenML

The [Mini](https://huggingface.co/KittenML/kitten-tts-2-mini),
[Nano](https://huggingface.co/KittenML/kitten-tts-2-nano), and
[Pico](https://huggingface.co/KittenML/kitten-tts-2-pico) KittenTTS 2
checkpoints are Apache-2.0 text-to-speech models. The model cards
document local inference with the KittenTTS package.
