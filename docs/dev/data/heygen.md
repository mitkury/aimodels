# HeyGen

OpenRouter documents the [Decision 1](https://openrouter.ai/heygen/heygen-decision-1)
and [Decision 1 Turbo](https://openrouter.ai/heygen/heygen-decision-1-turbo)
selectors on its Decisions API. Both take text and images and select answers
without output tokens. The catalog uses the documented selectors without
the provider namespace. A direct HeyGen model endpoint has not been verified.
