# Alibaba Cloud

The November 25 [Model Studio release log](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/newly-released-models)
lists the Beijing production selector `decision-model`. The [System One API reference](https://help.aliyun.com/en/model-studio/decision-model-api)
specifies 268,288 tokens, text and image inputs, and scores returned by the
`systemone` endpoint. There is no generated text. The hostname requires the
customer's workspace ID and region, so the catalog leaves the static API URL
unset. [Company information](https://www.alibabacloud.com/en/press-room/latest-ai-technologies-and-new-logo-unveiled-by-alibaba-cloud?_p_lc=1)
dates Alibaba Cloud to 2009.
