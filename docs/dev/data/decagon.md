## November 27, 2026 audit

Decagon released [Decibel-30B-A3B-v0](https://huggingface.co/decagon-ai/Decibel-30B-A3B-v0)

contains Apache 2.0 weights for a text and audio decision model that returns
choice probabilities without generating tokens.
