# Recraft

Recraft's [November 13 changelog](https://recraft.canny.io/changelog)
announces V4.1 Flash V2 as `recraftv4_1_flash_v2` on the
[image API](https://www.recraft.ai/docs). The
[endpoint reference](https://www.recraft.ai/docs/api-reference/endpoints)
supports up to six images per request at the published
[1K sizes](https://www.recraft.ai/docs/api-reference/appendix). [OpenRouter](https://openrouter.ai/recraft/recraft-v4.1-flash-v2)
uses `recraft/recraft-v4.1-flash-v2`.
