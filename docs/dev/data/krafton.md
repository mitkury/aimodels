# KRAFTON

[Raon API model documentation](https://raon-mini.krafton.ai/en/docs/models)
lists `raon-1-mini` at `https://raon-api.krafton.ai/v1`. It has a unified
262,144-token context, text input and output, reasoning, function calling, and
[JSON Schema output](https://raon-mini.krafton.ai/en/docs/structured-outputs).
The [first-party weight card](https://huggingface.co/KRAFTON/Raon-1-mini) links
the Apache-2.0 checkpoint and explains local deployment. The exact hosted
launch date and hard output cap are unverified.
[KRAFTON's press room](https://press.krafton.com/About-KRAFTON) documents its
founding and location.
