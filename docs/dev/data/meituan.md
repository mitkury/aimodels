LongCat 2.5 launched November 2, 2026, with a callable API and
[MIT weights](https://huggingface.co/meituan-longcat/LongCat-2.5). The
model understands text, images, and video. The API documents a 1M context,
256K output, structured outputs, and function calling.

[LongCat Flash Lite](https://huggingface.co/meituan-longcat/LongCat-Flash-Lite)
is an MIT text checkpoint with tools, 68.5B total parameters, about 3B active
parameters, and 256K context through YaRN. It has no verified route on the
current LongCat API.
